# 业务术语表

| 术语 | 定义 |
|---|---|
| 触点载体 | NFC 触点载体资产及其 UID、批次、入口关联和资产状态 |
| 入口 Link | 写入 NFC/NDEF 的稳定入口链接标识 |
| Payload | 触点载体实际写入或编码的内容 |
| 目标资源 | 银行业务侧可被路由规则选择的地址或资源对象 |
| 路由规则 | 根据作用域、优先级和有效期选择目标资源的规则 |
| 路由发布 | 将确认后的目标配置提交给 LinkForty 的过程 |
| 点击事件 | LinkForty 运行时产生的访问事实 |
| 触碰事件 | 点击事实关联触点载体、绑定和路由快照后的本地业务记录 |
| Webhook | LinkForty 向银行后台发送事件通知的协议机制 |
| 操作审计 | 记录操作人、命令、对象、变更和结果的追责记录 |
| 数据范围 | 用户可访问的本人、机构或全局数据集合 |
