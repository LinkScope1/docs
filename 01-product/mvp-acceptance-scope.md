# V1.3.2 MVP 验收范围

## 纳入范围

正式业务模块为 M1～M5；统计与报表作为不编号横向能力验收。

- Casdoor 登录、JWT 验证、`employee_code` Claim 和员工状态校验
- 组织编码前缀层级和员工维护
- NFC 触点资产和载体内容
- 资产与员工绑定、解绑、转交及无快照历史
- Webhook 验签、幂等和访问事件关联
- 点击、访问、安装和 App 事件统计与报表（非编号横向能力）
- 基于 `org_id`、`employee_id` 的数据范围、导出和操作审计
- 文档导入的模板、稳定匹配键、预校验和逐行结果契约预留
- LinkForty 外部调用结果可通过 M1 的 `operation_logs`、`trace_id` 和异步任务日志追踪

## 当前版本不纳入

- 所有本地 `iam_*` 表
- 目标资源表和目标资源管理
- 路由规则表和路由发布
- 路由冲突、实时路由计算和目标资源二选一
- 导入任务表及异步导入实现
- 银行业务办理量和办理金额
- 二维码和条形码完整业务流程
- 复杂审批流、完整版本可视化回滚和自动化 NFC 写卡

## MVP 完成标准

- JWT 中的 `employee_code` 能定位启用员工。
- 所有业务查询、写入、导出和导入预留接口完成权限和数据范围校验。
- 组织编码前缀规则、资产编码/UID 唯一性和绑定时间约束通过测试。
- 绑定历史不含名称快照且不因主数据删除产生级联失效。
- `touchpoint_payloads` 不包含 LinkForty 专属同步状态字段。
- `event_id` 并发幂等测试通过。
- 关键命令和导出都有审计记录。
