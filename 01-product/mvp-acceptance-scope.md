# MVP 验收范围

## 纳入范围

- Casdoor 登录、JWT 验证和本地 IAM 映射
- 组织和客户经理维护
- NFC 触点资产和 Payload 管理
- 绑定、解绑、转交和历史快照
- 目标资源管理
- 路由规则配置和 LinkForty 发布
- Webhook 验签和访问事件幂等
- 点击、访问、安装和 App 事件统计
- 数据范围、导出和操作审计

## 不纳入范围

- 银行业务办理量和办理金额
- 实时点击路由计算
- 二维码和条形码完整业务流程
- 复杂审批流
- 完整版本可视化回滚
- 自动化 NFC 写卡，除非硬件和 SDK 已确认

## MVP 完成标准

- 登录、资产、绑定、发布、事件和统计流程可通过前端完成。
- 所有 API 完成权限和数据范围校验。
- `event_id` 并发幂等测试通过。
- LinkForty 失败可重试、追踪和人工处理。
- 关键命令和导出都有审计。
- 迁移、备份、恢复和回滚经过验证。
