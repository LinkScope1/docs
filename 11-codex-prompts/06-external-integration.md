# 外部系统集成模板

```text
请实现或分析以下外部系统集成：

外部系统：
[Casdoor / LinkForty / Webhook / NFC]

调用方向：
[银行后台调用外部系统 / 外部系统调用银行后台]

接口或事件：
[填写]

必须确认或实现：
- 认证方式
- 请求和响应字段
- 签名验证
- issuer、audience、subject 或 API 凭证
- 超时和连接池
- 重试次数和退避策略
- 幂等键
- 外部请求 ID
- 失败状态
- 死信或人工补偿
- 监控指标和告警
- 联调测试方法

强制约束：
- LinkForty 写入必须通过 API。
- 不得直接执行 LinkForty 平台表 DML、DDL 或迁移。
- `click_id` 不得作为唯一键。
- Webhook 到达时间和事件发生时间必须区分。
- 不得把外部调用成功当成本地事务全部成功。
- 不得记录 Token、Secret 或密码。

如果契约无法确认，请标记待确认并给出推荐默认方案，不得编造真实接口字段。
```
