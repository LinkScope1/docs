# 发布和运维模板

```text
请为以下功能或版本制定发布、部署和运维方案：

版本或功能：
[填写]

环境：
[开发 / 测试 / 预生产 / 生产]

请检查：
- 环境变量和敏感配置
- 数据库迁移顺序
- 配置差异
- 健康检查
- 日志、Trace ID 和审计
- 指标、看板和告警
- 数据库备份
- 恢复演练
- 应用回滚
- 数据库回滚或前向修复
- 外部系统故障处理
- 发布后验证
- 变更记录

必须给出：
- 发布前检查表
- 执行步骤
- 成功判定
- 失败判定
- 回滚触发条件
- 回滚步骤
- 责任人和通知对象
- 监控指标及告警阈值建议

不得暴露 Token、密码、Webhook Secret 或数据库密码。
```
