# 测试和验收模板

```text
请为以下功能制定或实现测试：

功能：
[填写]

请覆盖：
- 单元测试
- Service 测试
- Repository 测试
- API 集成测试
- 前端组件测试
- Playwright 端到端测试
- 权限测试
- 数据范围越权测试
- 并发幂等测试
- Webhook 重复、乱序和缺失字段
- LinkForty 超时、失败和重试
- 状态机和历史快照
- 数据库迁移
- 性能和安全
- 回滚和恢复

每个关键流程至少覆盖：
- 正常场景
- 参数错误
- 权限失败
- 数据范围越权
- 业务规则冲突
- 对象不存在
- 重复请求
- 外部系统失败
- 数据库失败
- 重试后的最终状态

要求：
1. 先检查现有测试框架、夹具和测试数据。
2. 不得只测试 HTTP 200，必须验证状态、数据、审计和幂等结果。
3. 不得输出未实际执行的测试结果。
4. 最终给出通过、失败、未执行和原因。
```
