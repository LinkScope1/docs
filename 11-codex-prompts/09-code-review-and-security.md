# 代码审查和安全审查模板

```text
请审查当前分支相对于目标分支的变更。

目标分支：
[main 或其他分支]

重点检查：
- 业务逻辑正确性
- 权限绕过和数据范围越权
- SQL 注入和不安全查询
- JWT、Token、密码和 Secret 泄露
- Webhook 重放和签名绕过
- 幂等漏洞
- 事务不完整
- 外部调用失败处理
- 数据库迁移和回滚风险
- 测试缺失
- 是否违反 AGENTS.md 和 docs 设计基线

每个问题必须包含：
- 严重级别：Blocker / Critical / Major / Minor
- 文件路径和代码位置
- 问题描述
- 影响范围
- 修复建议

如果没有发现问题，也要说明审查范围、执行的检查和未覆盖的内容。
```
