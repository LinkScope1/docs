# 文档和 ADR 编写模板

```text
请编写或更新以下文档：

文档类型：
[需求 / API / 数据字典 / 架构 / ADR / 测试 / 部署 / 运维]

主题：
[填写]

相关代码和文档：
[填写路径]

要求：
- 先检查现有文档和代码事实。
- 明确区分已确认、待确认、建议和阻塞。
- 不把建议写成业务承诺。
- 不把设计内容写成已实现功能。
- 影响架构、数据边界、权限或外部契约时创建或更新 ADR。
- 文档变更后同步更新索引或交叉链接。
- 保留现有文档中仍然有效的内容。

请输出：
1. 当前事实和证据
2. 文档变更方案
3. 新增或修改内容
4. 待确认事项
5. 对代码、测试和发布的影响
```
