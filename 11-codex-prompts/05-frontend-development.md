# React 前端开发模板

本模板的任务 ID、依赖和页面验收标准来源于[详细开发任务清单](../00-project/development-task-checklist.md)；前端、权限、API 和 UI 规则仍以对应规范为准。

```text
请实现或审查以下银行后台前端功能：

详细任务清单 ID：
[填写 P1-FE-*、F-COM-*、F-M1-*～F-M5-*、F-ANL-*、F-EXP-*、T-FE-* 或 T-E2E-* 任务 ID]

前置依赖及状态：
[填写完整任务 ID、DEC-*、ENV-* 或 EPIC-*，并确认依赖不是“阻塞待确认”或“延期”]

关联权威文档：
[填写前端指南、权限规范、API 契约、页面规范和 UI 验收文档链接]

页面或功能：
[填写]

页面路径：
[填写]

请明确处理：
- 路由和菜单权限
- 本人、机构、全局三类数据范围
- 列表、详情、表单、弹窗和批量操作
- 加载、空数据、参数错误、权限失败和接口失败状态
- React Query 查询、缓存和失效策略
- React Hook Form/Zod 或项目现有表单校验
- API 类型来源和错误码映射
- 操作按钮权限
- 导出权限和导出审计
- Playwright 端到端验收场景
- 详细任务清单中的页面、状态和验收标准

要求：
1. 先检查现有页面、路由、组件和 API 类型。
2. 开始实现前确认任务状态不是“阻塞待确认”或“延期”；未满足依赖时先报告阻塞。
3. 不把前端隐藏按钮当作安全控制，后端权限仍必须生效。
4. 只修改本页面和其必要依赖。
5. 提供正常、空数据、异常和无权限状态。
6. 完成后报告修改文件、任务状态变化和测试结果。
```
