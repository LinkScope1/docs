# React 前端开发模板

```text
请实现或审查以下银行后台前端功能：

页面或功能：
[填写]

页面路径：
[填写]

请明确处理：
- 路由和菜单权限
- 本人、机构、全局三类数据范围
- 列表、详情、表单、弹窗和批量操作
- 加载、空数据、参数错误、权限失败和接口失败状态
- React Query 查询、缓存和失效策略
- React Hook Form/Zod 或项目现有表单校验
- API 类型来源和错误码映射
- 操作按钮权限
- 导出权限和导出审计
- Playwright 端到端验收场景

要求：
1. 先检查现有页面、路由、组件和 API 类型。
2. 不把前端隐藏按钮当作安全控制，后端权限仍必须生效。
3. 只修改本页面和其必要依赖。
4. 提供正常、空数据、异常和无权限状态。
5. 完成后报告修改文件和测试结果。
```
