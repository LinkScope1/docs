# 代码库和文档分析模板

```text
本次只做分析，不修改任何代码或文档。

请先读取 AGENTS.md、docs/README.md 和与任务相关的设计文档，再检查当前仓库。

分析对象：
[填写模块、目录、功能或文档]

请检查：
- 目录和技术栈
- 已实现模块
- 部分实现模块
- 仅有技术落点但未形成业务闭环的模块
- 待开发模块
- 已有 API、数据库表、迁移、页面和测试
- 权限、数据范围、状态和幂等
- 外部系统调用和失败处理
- 文档与代码差异

请按以下结构输出：
1. 执行摘要
2. 代码证据
3. 已实现
4. 部分实现
5. 技术落点但业务未闭环
6. 待开发
7. 文档与代码冲突
8. 风险和待确认事项
9. 推荐开发任务和优先级

所有结论必须附文件路径、类名、函数名、接口路径或测试证据。
不能确认的内容标记为“待确认”，不得编造结论。
```
