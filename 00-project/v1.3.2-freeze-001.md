## 2. 已冻结的本地基线

- 银行后台只拥有 `bank_admin` Schema 的 7 张业务表。
- 正式业务模块固定为 M1～M5；旧 M6～M8 只允许出现在历史迁移说明中。
- Casdoor 是身份、角色和功能权限权威；银行后台不创建本地 `iam_*` 表。
- LinkForty 写入只能通过 API；LinkForty 表不得由银行迁移或业务 Repository 修改。
- `event_id` 是访问事件全局幂等键，`click_id` 只作非唯一逻辑引用。
- `access_events.asset_id` 非空；资产无法唯一解析时不得写入 `access_events`。
- Payload 不保存外部同步状态；外部调用结果由 M1 审计并通过 `trace_id` 关联。
- 绑定只追加历史，解绑结束当前记录；V1.3.2 只支持立即生效绑定。
- 导入只提供同步预校验；异步执行、任务状态和结果持久化延期 V1.4。
- V1.3.2 同步导出默认限制为 10 MiB 或 100,000 行；异步导出延期 V1.4。
- 统计只读 M5 本地事件和 LinkForty 白名单事件字段，不创建本地统计表。

## 4. 外部证据关闭条件

外部证据不得用占位 URL、虚构 Claim、模拟负责人签字或 Mock 成功结果替代。每项证据必须包含：负责人角色、确认日期、环境、结论、脱敏样例或测试报告路径。

### Casdoor

- 必须提供测试 issuer、audience、JWKS URI 和允许算法。
- JWT 必须包含非空字符串 `employee_code` 和非空 `sub`。
- 后端默认使用 60 秒时钟偏差；员工不存在或停用返回 401/403。
- 未知 `kid` 触发 JWKS 刷新，不能保存私钥。

### LinkForty

- `POST /api/links` 必须支持稳定 `Idempotency-Key` 或等价的服务端幂等语义。
- 同 Key 同 Payload 返回首次对象；同 Key 不同 Payload 返回冲突。
- 4xx 不重试；429、5xx、超时使用指数退避，最多 3 次。
- 只读账号不得读取 `webhooks` 或 `webhooks.secret`，不得执行 DML、DDL、TRUNCATE。

### NFC

- 确认 UID 读取、NDEF 编码、最大长度、写入失败和读回核验结果。
- 真机不是软件 MVP 的成功依据；Mock 必须能模拟失败且不得伪造真机成功。

## 5. 变更控制

- 冻结后的 API、字段、状态或权限变化必须创建新的 `DEC-*` 记录。
- 任何数据库修正必须新增 Alembic revision，不修改已应用 revision。
- 外部契约变化必须同时更新 Integration Adapter、OpenAPI、测试和本记录的证据状态。
- P0 只有在“外部证据待补”全部清零、验证命令有结果、负责人完成评审后才能改为 `FROZEN`。
