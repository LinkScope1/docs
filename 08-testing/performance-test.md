# 性能测试方案

## 重点场景

- 组织和资产列表分页。
- 绑定冲突校验。
- Webhook 并发接收。
- 访问事件查询。
- 统计查询。
- 大数据量导出。

## 测试指标

- 平均响应时间。
- P95/P99 响应时间。
- 吞吐量。
- 错误率。
- 数据库连接池使用率。
- Celery 任务积压。
- 统计查询耗时。

V1.3.2 保守门槛：列表接口 P95 ≤ 500 ms，访问事件接口 P95 ≤ 1 s，统计接口 P95 ≤ 2 s，同步导出 P95 ≤ 5 s。

- 错误率必须小于 1%，Celery 队列积压必须小于 100，发布后观察窗口为 30 分钟。
- P99 必须记录，但本版本只作为观测指标，不作为额外关闭门槛；超过 P95 门槛时按回滚/延期规则处理。
- 报告必须记录固定测试数据量、并发量、数据库连接池、慢查询、Redis 和 Celery 指标。没有这些命令结果不得标记性能通过。
