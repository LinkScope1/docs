# 前端权限规范

- Casdoor 返回的权限集合是前端权限判断的唯一输入；不根据角色名称写死业务逻辑。
- 菜单配置同时维护 Casdoor 权限码和独立的 `data-testid`，两者不得复用。
- 菜单按权限展示，路由进入时再次检查权限，按钮按权限展示或禁用。
- 路由守卫、菜单和按钮必须使用统一权限上下文，不能各自解析 Token 或实现一套权限判断。
- 权限码未确认、映射缺失或权限上下文未加载完成时，按失败关闭处理。
- 前端权限只改善体验，不作为安全边界；后台仍必须校验功能权限和数据范围。
- 401 统一进入登录或会话失效流程；403 展示权限或数据范围提示。
- 导出、导入、解绑、转交、停用、作废和发布按钮必须绑定对应权限，并展示后端返回的范围或影响提示。
