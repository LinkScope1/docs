# UI 验收规范

每个页面验收：

- [ ] 正常数据展示
- [ ] 空数据展示
- [ ] 加载中展示
- [ ] 请求失败展示
- [ ] 权限不足展示
- [ ] 表单必填和格式校验
- [ ] 危险操作二次确认
- [ ] 成功后刷新数据
- [ ] 分页、筛选和排序可用
- [ ] 移动或窄屏下无关键内容遮挡
- [ ] 菜单拥有稳定 `data-testid`
- [ ] 业务按钮拥有稳定 `data-testid`
- [ ] 菜单/按钮 `data-testid` 与权限码没有混用
- [ ] 页面未直接调用 `fetch`、`axios`
- [ ] 页面通过领域 Service 或 Hooks 获取和修改数据
- [ ] 401、403、网络错误和后端业务错误使用统一交互
- [ ] 成功 Mutation 后按约定刷新 Query 缓存
- [ ] 重复提交、重复导出和危险操作受到统一控制
- [ ] Playwright 不依赖易变文本或 DOM 顺序定位核心菜单和按钮
