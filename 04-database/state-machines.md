# V1.3.2 状态机

## 触点资产

```text
库存 -> 启用 -> 停用 -> 永久作废
```

永久作废不可恢复。资产 `org_id`、`employee_id` 与绑定变更在同一业务事务内同步维护。

LinkForty 外部调用的重试和补偿属于 Worker 任务处理过程，不构成银行业务状态机。调用结果通过 `trace_id`、任务日志和 M1 的 `operation_logs` 追踪，`touchpoint_payloads` 不保存外部同步状态。

## 绑定

```text
当前有效 -> 已解绑
```

绑定历史只追加，不覆盖；同一资产有效时间区间不能重叠。V1.3.2 不保存名称快照。

## 访问事件关联

```text
待关联 -> 关联成功
       -> 待重试 -> 关联成功
       -> 最终失败
```

缺少 `event_id` 的 Webhook 拒绝处理；重复 `event_id` 返回幂等成功。

## 操作日志

操作日志只追加。所有创建、修改、启停、绑定、解绑、调拨、导入、导出和外部同步命令记录操作人、组织范围、前后必要字段和结果。
