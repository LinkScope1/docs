# 状态机

## 触点资产

```text
库存 -> 启用 -> 停用 -> 永久作废
```

## 配置

```text
待配置 -> 正常 -> 异常
```

## Payload 外部同步

```text
待同步 -> 同步中 -> 成功
                    -> 失败 -> 待补偿
```

## 路由发布

```text
草稿 -> 待确认 -> 发布中 -> 发布成功
                         -> 发布失败 -> 待补偿
```

## 绑定

```text
预约 -> 生效 -> 已解绑
              -> 已转交
```

## 访问事件

```text
待解析 -> 已关联
       -> 关联失败 -> 待重试 -> 已关联
                            -> 最终失败
```

每个状态转换必须记录触发人、触发时间、前后状态、失败原因和审计要求。
