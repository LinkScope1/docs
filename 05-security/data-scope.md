# V1.3.2 数据范围方案

## 字段语义

- `org_id`：当前数据责任组织。
- `employee_id`：当前直接责任员工。
- `employees` 表以自身 `id` 作为员工 ID，不增加自指字段。
- 系统事件、公共数据和库存资产可以没有直接责任员工。

## 范围类型

- 本人：当前员工 `employee_id` 对应的数据。
- 机构：当前员工所属组织及组织编码前缀表示的递归下级组织。
- 全局：全部组织数据。

## 规则

- 后端必须执行数据范围过滤。
- 前端传入的 `employeeId` 或 `orgId` 不能决定权限。
- 员工只维护一个直接所属组织。
- 资产、载体内容和绑定变更时，责任范围字段在同一事务中同步。
- 访问事件在关联成功后写入事件组织和员工；未关联事件允许范围字段为空。
- 导出和导入使用与页面查询相同的数据范围。
- 绑定、停用和导入命令必须同时校验功能权限和数据范围。
