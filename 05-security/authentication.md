# 认证方案

## Casdoor

Casdoor 负责身份、角色和功能权限。银行后台负责 JWT 验证、主体映射、API 映射和组织数据范围。

## 验证步骤

1. 获取并缓存 JWKS。
2. 验证 JWT 签名。
3. 验证 issuer。
4. 验证 audience。
5. 验证 subject。
6. 验证过期时间和时钟偏差。
7. 映射 `iam_users`。
8. 检查本地用户状态。
9. 构建认证和数据范围上下文。

## 禁止

- 本地保存密码。
- 本地保存 Token。
- 使用前端按钮代替权限。
- 用 query 参数中的用户 ID 代替 JWT 主体。
